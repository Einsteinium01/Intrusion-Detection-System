Intelligent Network Traffic Analyzer

High-Level Runtime Architecture & Primary Detection Pipeline

Primary Pipeline: Ingestion to Dashboard

  • • Step ① (Tap): Captures live packets via Scapy / raw sockets in a non-blocking thread ring buffer.
  • • Step ② (Flow Extraction): Aggregates bidirectional flows (IP 5-tuples) and calculates 78+ statistical attributes over a sliding window.
  • • Step ③ (Inference Scoring): The singleton Detection Engine evaluates feature vectors against pre-trained XGBoost and Random Forest models.
  • • Step ④ (Gateway Dispatch): Threat classifications trigger alert events; periodic status updates (every 500ms) summarize flow metrics.
  • • Step ⑤ & ⑥ (UI Stream): Flask-SocketIO pushes alerts instantly to the React console with 10 pkt/s display throttling to avoid client lag.

Trust Boundaries & Perimeter Security

  • • Untrusted Ingress Zone: Raw network packets and external HTTP requests enter via untrusted boundaries; raw payloads are sanitized and inspected without direct execution.
  • • Local IDS Runtime Boundary: Packet sniffer, ML models, and Flask backend operate within an isolated local host process. Endpoints enforce strict CORS against unauthorized origins.
  • • API Hardening: Follows OWASP API doctrine: strict bounded limit params (max 500), no stack traces leaked in error responses, and anti-sniff headers on all responses.
  • • AI Egress Isolation: Outbound calls to cloud LLMs (Groq/OpenAI) traverse an explicit TLS boundary with API tokens stored strictly in environment variables.

Asynchronous AI & RAG Enrichment

  • • Queue Decoupling: Heavy LLM generation is completely isolated from real-time packet capture via a dedicated background task queue (AIManager).
  • • Knowledge Retrieval (RAG): Alerts query the local MITRE ATT&CK knowledge vector index to pull relevant adversary tactics, techniques, and IDs.
  • • Root Cause Synthesis: The Alert Analyzer packages telemetry + MITRE documentation to generate incident explanations and remediation recommendations.
  • • Additive Architecture: If the AI service is disabled or encounters network latency, core packet capture and ML classification continue without interruption.
