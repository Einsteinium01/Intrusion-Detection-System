Network Traffic Analyzer Architecture

High-level runtime execution flow and data paths

Detection Pipeline (Primary Path)

  • • Packet Sniffer reads raw traffic via Scapy or pcap
  • • Feature Extractor computes aggregated flow statistics
  • • Detection Engine passes stats to ML Models
  • • ML Models classify flows as BENIGN or attack types
  • • Alerts emitted to API Server and Socket.IO clients

AI Enrichment & RAG

  • • Queue Manager gathers background investigation requests
  • • Vector Store retrieves knowledge (MITRE ATT&CK context)
  • • Alert Analyzer builds prompt with alert info + RAG
  • • LLM API synthesizes root cause & response guidelines

Trust Boundaries

  • • Local Network encapsulates capture and ML inferencing
  • • Strict CORS applied to React dashboard API access
  • • Rate limiting prevents unrestricted resource consumption
  • • External API connects to LLM over secure TLS
